# Change log against main

**Reviewed: 26 September 2026 (Asia/Singapore).** This compares the current `at-experiments` workspace with local `main` at **`633afda` (`Job PBS fix`)**, including staged, unstaged, and untracked files. Both branches currently point to that commit; the changes described here are **uncommitted**, not merged or released. The date records this review, not the implementation date of every item.

## Existing foundation in main

The base branch already provided AgentDojo tool interception, per-task review budgets, full-approve, full-escalate, the tool-name cascade, an LLM-simulated reviewer, benchmark/sweep scripts, a basic TCR plotter, an OpenAI-compatible client with explicit temperature/seed settings, and the PBS launcher. Those components were extended; they should not be presented as newly introduced policies or infrastructure.

## Compatibility and scope

- The new runner defaults to `results/experiments` and writes per-episode manifests/ledgers. The legacy TCR reader still supports older flat logs; the new HITL and cost reports need the new records.
- `undefended` now uses the instrumented full-approval execution path in the shared episode runner, rather than the former stock AgentDojo pipeline construction.
- The current runner verifies models through Ollama's native `/api/tags` and `/api/version` endpoints in addition to OpenAI-compatible inference. Another server needs corresponding integration; generic inference compatibility alone is insufficient for this runner.
- `server_context_length` records the expected setting and participates in experiment identity. It does not change the running Ollama server's context configuration.
- The original explicit temperature/seed handling, full-approve/full-escalate budget semantics, and PBS launcher are not new fixes. Missing AgentDojo installation or `.env` configuration is addressed through setup instructions; no automatic dependency installation or API-key fallback was added.

## Still open; not implemented fixes

- **Budget-dependent risk estimates:** the evaluated risk classifier can approve an injected action at a larger budget after rejecting or reviewing it at a smaller budget. Separating authorization risk from budget allocation remains proposed work.
- **VOI repeated denials:** the evaluated value policy frequently denies useful read-only proposals and performs worse than learned risk. Uncertainty-aware overrides and additional training trajectories under the revised policy remain proposed work.
- **Six failed training branches:** long-context `no user query found in messages` and repetitive-generation failures remain excluded from training. A 32K render-only diagnostic addressed prompt construction for three histories; full continuation success and the repetition issue have not been resolved.
- **Research validation:** the smaller 504-episode validation is completed. Its 1,624 executed calls remain unaudited for strict authorization; the main held-out test and additional research comparisons are deferred. Implementing a policy or optional comparator does not establish improved safety or state-of-the-art performance.
